[[SOUL]]

## Convention

Each memory is a single file in this folder. Filename: `YYYY-MM-DD — Topic.md`

### Format

- **Date**: when it happened
- **Type**: decision | lesson | context | status
- **Content**: what happened and why it matters
- **Expiry** (optional): when this memory stops being relevant

### Types

- **Decision** — a choice that was made and why. Agents should respect this until told otherwise.
- **Lesson** — something that didn't work, or worked better than expected. Prevents repeating mistakes.
- **Context** — active state an agent needs to know (tool versions, infra details, current priorities).
- **Status** — where a project or initiative stands right now. Agents should update these, not create new ones.
