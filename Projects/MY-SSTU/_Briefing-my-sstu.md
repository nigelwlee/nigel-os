## Listing SOP

**Title format:** Pipes (|) separated, 140 chars max, ends with "(Digital Download)"

**Tags:** Max 20 chars each, no numbering

**Assembly instructions:** Text format (not PDF)

**Standard specs:**
- 216gsm / 80lb cardstock
- Basic cut
- 5x7 card size
- Difficulty scale 1–5

**Claude Project template exists** (uuid: `019c1334`) for batch listing generation.

---

## Key Decisions

- Digital-only (no physical shipping)
- Affinity Designer for asset creation
- Claude for listing copy generation — standardised workflow
- SVG format for Cricut compatibility
